---
name: cleanup-branches
description: Убирает лишние ветки — и на GitHub, и локально. Вызывать после
  мержа PR, или когда список веток захламлён (влитые/удалённые ветки
  продолжают висеть в локальном репозитории).
---

Репозиторий настроен на автоудаление веток при мерже PR (GitHub: Settings →
General → "Automatically delete head branches"), но локальные копии этих
веток на компьютере каждого разработчика сами по себе не исчезают — их
нужно чистить отдельно.

1. `git fetch --prune origin` — подтягивает актуальный список веток с GitHub
   и убирает локальные ссылки (`origin/...`) на то, чего там больше нет.
2. Найди локальные ветки, у которых remote-ссылка теперь "gone" (то есть
   ветку удалили на GitHub, обычно после мержа):
   `git branch -vv | grep ': gone\]'`
3. Удали каждую такую ветку через `git branch -d <имя>` (именно `-d`, не
   `-D` — так git откажется удалить ветку, если в ней вдруг остались
   незамерженные изменения, и это нормально — сначала разберись, что в ней).
4. Никогда не трогай текущую ветку и `main`.
5. Кратко перечисли, что удалено, и если `git branch -d` для чего-то
   отказал — отдельно скажи, что осталось незамерженным и почему.
