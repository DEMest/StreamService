# UX Navigation & Watch Page Redesign — Design Spec

**Date:** 2026-04-13
**Status:** Approved

---

## Goal

Привести UI к модели, близкой к Twitch: публичный хедер на всех страницах, студийный сайдбар в дашборде, переработанная страница просмотра с мультикам-режимами и сворачиваемым чатом.

---

## Section 1: Layout Architecture & Routes

### PublicLayout
Оборачивает все публичные страницы. Содержит `<Header>` сверху и `<main>` снизу.

**Страницы:**
- `/` — главная (live + все орги)
- `/watch/[orgSlug]` — страница просмотра
- `/login` — авторизация
- `/admin` — панель суперадмина

### DashboardLayout
Оборачивает все страницы дашборда. Левый фиксированный сайдбар + `<main>`.

**Страницы:**
- `/dashboard` и все вложенные маршруты

---

## Section 2: Public Header

Фиксированная высота ~56px, присутствует на всех PublicLayout страницах.

- **Слева:** логотип/название — ссылка на `/`
- **Справа:**
  - Не авторизован: кнопка "Войти" → `/login`
  - Авторизован: имя пользователя + ссылка "Студия" → `/dashboard`

## Section 3: Watch Page

### Режимы просмотра

Заменяют старые `quad` / `focus`. Новые режимы:

| Режим | Описание |
|-------|----------|
| `multicam` | Все 4 квадранта видны (scale 1×) |
| `cam1` | Кроп на квадрант 1 (scale 2× + translate) |
| `cam2` | Кроп на квадрант 2 |
| `cam3` | Кроп на квадрант 3 |
| `cam4` | Кроп на квадрант 4 |

Переключение: клик/тап по конкретной области в режиме `multicam` (не drag).
`QUAD_ORIGIN` карта остаётся, но теперь используется для всех 5 режимов.

### Desktop поведение

- Чат — правая панель, кнопка сворачивания (‹/›). При свёрнутом чате видео занимает всю ширину.
- Ховер мышью к левому краю экрана → выезжает боковая панель режимов (Multicam / Cam1–4).
- Панель режимов скрывается при уходе мыши.

### Mobile поведение

- Полноэкранный режим по умолчанию.
- После 3 секунд неактивности UI-оверлеи скрываются.
- Тап по экрану → показать UI.
- **Слева:** иконка-стрелка → выезжает панель режимов (Multicam / Cam1–4).
- **Справа:** иконка-стрелка → выезжает чат.

## Section 4: Dashboard (Студия)

### Сайдбар

- ← На сайт → `/`
- Моя страница → `/watch/[orgSlug]`
- **Трансляция** — текущее событие, SRT-ключ (формат `srt://<host>:8890?streamid=publish:live/<slug>`)
- **События** — список событий, кнопка "Создать"
- **Настройки** — название организации, описание

### Управление событиями

- Каждое событие в списке: название, статус (live/scheduled), кнопка удаления
- Удаление — с подтверждением (диалог "Вы уверены?")
- Приватные события: иконка замка + кнопка "Скопировать ссылку превью"
  Ссылка: `https://<host>/watch/<orgSlug>?key=<previewKey>`

## Section 5: Backend Changes

### Схема Prisma

```prisma
model Organization {
  // existing fields...
  description String? // новое поле
}

model Event {
  // existing fields...
  previewKey String? @unique // новое поле, только для isPublic=false
}
```

### Новые / изменённые эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/v1/public/orgs` | Список всех организаций (для главной страницы) |
| `GET` | `/v1/public/orgs/:slug` | Уже есть; добавить `description` в ответ |
| `DELETE` | `/v1/dashboard/events/:id` | Удаление события (только владелец) |
| `GET` | `/v1/public/orgs/:slug/preview` | Проверка `?key=TOKEN` для приватного события |

---

## Section 6: Preview Key (приватные события)

- При создании события с `isPublic: false` сервер генерирует `previewKey` — `crypto.randomUUID()` или `randomBytes(32).toString('hex')`.
- Ключ хранится в `Event.previewKey`, привязан к событию.
- Ключ не истекает по времени; один ключ на событие (переиспользуемый).
- **Доступ**: `/watch/[orgSlug]?key=<previewKey>` — фронт передаёт ключ при запросе к `/v1/public/orgs/:slug/preview?key=TOKEN`.
- Без ключа (или с неверным) — страница показывает "Трансляция недоступна".
- В дашборде: кнопка "Скопировать ссылку" копирует полный URL в буфер через `navigator.clipboard`.

## Out of Scope (MVP)

- Красивый дизайн / стилизация — минимальный CSS, приоритет функциональности
- Множественные ключи / ротация ключей
- Статистика просмотров
- Разделение на 4 отдельных потока
