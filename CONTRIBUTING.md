## Права на вклад

Это главный раздел, а не формальность. По умолчанию исключительное право на
любой написанный код принадлежит его автору — то есть без договорённости ниже
права на репозиторий оказались бы разделены между всеми, кто в него что-то
коммитил, и правообладатель не смог бы ни сменить лицензию, ни защитить
проект.

Отправляя изменения (pull request, патч, коммит в ветку этого репозитория), вы
подтверждаете, что:

1. **Передаёте правообладателю** — Смолину Даниилу Леонидовичу — исключительное
   право на свой вклад в полном объёме: безвозмездно, на весь срок действия
   исключительного права, на территории всего мира, без ограничения способов
   использования.
2. **Вклад создан вами лично** и не нарушает прав третьих лиц: это не чужой
   код, не результат работы по договору с другим заказчиком и не фрагмент,

3. **Вы не включаете в вклад** код под копилефт-лицензиями (GPL, AGPL, LGPL и

4. **Вы сохраняете право авторства** — оно неотчуждаемо и остаётся за вами;

Новые зависимости — отдельный случай: перед добавлением пакета проверьте его
лицензию. MIT, Apache-2.0, BSD, ISC подходят. GPL/AGPL — нет.

## Секреты

Ничего похожего на учётные данные в репозиторий не попадает. `.env` и
`.env.local` закрыты в `.gitignore` — не обходите это `git add -f`.

Новая переменная окружения добавляется в `.env.example` **пустой или с явным
плейсхолдером**, с комментарием о назначении. Реальные значения живут только в
`.env` на сервере.

Если секрет всё-таки утёк в коммит: сообщите правообладателю сразу, до того
как ветка уедет на GitHub. Удаление файла следующим коммитом не помогает —
значение остаётся в истории, и его придётся отзывать и перевыпускать.

## Процесс

Правила ветвления и мержа описаны в [CLAUDE.md](CLAUDE.md) и обязательны:

- В `main` напрямую не пушим. Ветка → pull request → зелёный CI → мерж.
- Именование веток: `feat/`, `fix/`, `chore/`, `ci/`, `infra/` + краткое
  описание через дефисы.
- **Мерж в `main` — это релиз.** Автодеплой выкатывает изменения на
  liga-live.ru, где в этот момент может идти трансляция. Отдельного шага
  «задеплоить» нет.
- Изменения в `infra/mediamtx/*` и `docker-compose.yml` требуют перезапуска
  MediaMTX и обрывают приём потока у всех стримеров — такие правки
  согласовываются заранее.
- Мержим по одному PR за раз, дожидаясь окончания предыдущей выкатки.

```bash
pnpm --filter web exec tsc --noEmit && pnpm --filter web build
```
