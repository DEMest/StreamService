# Страница турнира: эфир, чат, лента схваток и архив

Дата: 7 ноября 2026. Статус: черновик, формулировки уточняются с заказчиком.
Документ серии, детализирующей [`../srs.md`](../srs.md). Описывает, как
зритель смотрит турнир на сайте и в основном приложении: эфир, чат, ленту
схваток — нарезку из трансляции и съёмку медиагентов
([`2026-11-07-media-agent-app.md`](2026-11-07-media-agent-app.md)), лайки и
комментарии к ним, а также что остаётся после турнира и как это найти в
архиве. Турнир, каналы, личные страницы и главный экран — в
[`2026-11-07-app-home-accounts-roles.md`](2026-11-07-app-home-accounts-roles.md).

Страница одинакова по составу на сайте и в приложении; порядок работ —
сначала веб ([`../development-principles.md`](../development-principles.md)).

Коды требований: FR-300 и дальше, NFR-80 и дальше.

---

## 1. Термины

| Термин | Значение |
|---|---|
| Страница турнира | Главная страница события: эфир, чат, лента схваток, расписание. Работает до турнира (предстоящий), во время и после |
| Эфир турнира | Каналы турнира (категория `tournament`) в плеере: композит 2×2 или раскладка нескольких каналов, по одному на ковёр. Необязателен |
| Турнир без трансляции | Турнир без каналов: на странице только шапка события и лента клипов медиагентов (§2.6) |
| Клип схватки | Видео одной схватки с подписью «кто с кем». Два источника: съёмка медиагента и нарезка из трансляции |
| Клип медиагента | Клип, снятый медиагентом на телефон, горизонтальный или вертикальный; выкладывается от канала медиагента |
| Клип трансляции | Клип, вырезанный из трансляции турнира — организатором руками или автоматически по таймкодам секретаря; выкладывается от канала организатора |
| Лента схваток | Список клипов турнира. Пополняется во время турнира, по мере того как медиагенты выкладывают съёмку |
| Мини-плеер | Свёрнутый плеер эфира в углу экрана: эфир продолжает играть, пока зритель листает приложение |

## 2. Как выглядит страница

### 2.1 Телефон, вертикально

```
 ┌──────────────────────────┐        ┌──────────────────────────┐
 │                          │        │                          │
 │   ПЛЕЕР: 4 экрана        │        │   ПЛЕЕР: 4 экрана        │
 │   (ковры 1–4)            │        │   (ковры 1–4)            │
 │                          │        │                          │
 ├──────────────────────────┤        ├──────────────────────────┤
 │ Турнир · организатор     │        │ Турнир · организатор     │
 ├──────────────────────────┤        ├──────────────────────────┤
 │ ЧАТ                    ⌄ │        │ [поиск по фамилии]   ЧАТ⌃│
 │ Анна: вперёд, Иванов!    │        │ ┌──────┐ Иванов — Петров │
 │ Олег: какой ковёр?       │        │ │превью│ ковёр 2 · 13:05 │
 │ …                        │        │ └──────┘ ♥ 12  💬 3      │
 │                          │        │ ┌──────┐ Сидоров — Козлов│
 │ (чат занимает всё        │        │ │превью│ ковёр 1 · 13:10 │
 │  под плеером)            │        │ └──────┘ ♥ 4   💬 0      │
 │ [написать сообщение]     │        │ …                        │
 └──────────────────────────┘        └──────────────────────────┘
     чат развёрнут                      чат свёрнут
```

- Плеер сверху, под ним строка с названием турнира.
- **Чат развёрнут** — он занимает всё пространство под плеером и
  перекрывает остальное.
- **Чат свёрнут** — под плеером открываются строка поиска и лента схваток,
  снятых медиагентами. Чат снова разворачивается одной кнопкой.
- Лента вертикальная: клипы идут один под другим, листаются вниз.
- **Сдвиг плеера вниз** сворачивает эфир в мини-плеер, и зритель уходит
  листать остальное приложение, не теряя эфир. Нажатие на мини-плеер
  возвращает страницу турнира.
- **Поворот телефона** — горизонтальный режим (§2.2).

### 2.2 Телефон, горизонтально

- Плеер на весь экран. Поверх — выбор камеры и раскладки, качество.
- Чат открывается полупрозрачной панелью сбоку и закрывается обратно.
- Поворот обратно — вертикальный режим с тем же состоянием чата.

### 2.3 Компьютер и планшет

```
 ┌──────────────────────────────────────────┬──────────────┐
 │                                          │              │
 │      ПЛЕЕР: 4 экрана (ковры 1–4)         │     ЧАТ      │
 │                                          │  (сворачива- │
 │                                          │  ется вбок)  │
 ├──────────────────────────────────────────┤              │
 │ Турнир · организатор · даты              │              │
 │ [Подписаться] [Заказать съёмку]          │              │
 ├──────────────────────────────────────────┤              │
 │ [поиск по фамилии]  [ковёр ▾]            │              │
 │ ┌──────┐ Иванов — Петров · ковёр 2       │              │
 │ │превью│ (●)(●) 13:05 · ♥ 12 · 💬 3      │              │
 │ └──────┘                                 │              │
 │ ┌──────┐ Сидоров — Козлов · ковёр 1      │              │
 │ │превью│ 13:10 · ♥ 4 · 💬 0              │              │
 │ └──────┘                                 │              │
 └──────────────────────────────────────────┴──────────────┘
```

- Чат справа, сворачивается вбок и отдаёт место плееру и ленте.
- Лента под плеером тоже вертикальная, один клип под другим.

### 2.4 Что везде одинаково

- **Плеер** — каналы турнира в раскладке на четыре экрана или композит
  2×2 с выбором камеры: всё, что умеет плеер сегодня (FR-11, FR-12,
  FR-13). Сервер кадр не пересобирает (SRS INV-1).
- **Подпись клипа** — мелким текстом пара, ковёр и время: «Иванов —
  Петров · ковёр 2 · 13:05», и от чьего канала клип: организатора
  (нарезка из трансляции) или медиагента. Если у участника есть аккаунт, рядом с
  фамилией его аватар; нажатие на аватар или фамилию открывает его личную
  страницу (FR-150).
- **Счётчики** — лайки и комментарии под каждым клипом (§3.6).
- **Поиск и фильтры** — над лентой, подробно в §2.5.

### 2.5 Поиск и фильтры под трансляцией

На турнире схваток сотни, поэтому лента без поиска бесполезна.

```
 ┌──────────────────────────┐
 │ [🔍 Иван…            ✕]  │  строка закреплена под плеером
 │  Иванов Пётр · Школа №3  │  подсказки по участникам турнира
 │  Иванов Сергей · «Барс»  │
 ├──────────────────────────┤
 │ (Ковёр 2)(до 60 кг)(Мои)→│  чипы фильтров листаются вбок
 ├──────────────────────────┤
 │ 13:00 ───────────────────│  группы по времени
 │ ┌──────┐ Иванов — Петров │
 │ └──────┘ …               │
 │ 12:30 ───────────────────│
 │ …                        │
 │                [К последним ↑]
 └──────────────────────────┘
```

- **Строка поиска закреплена** под плеером и не уезжает, когда лента
  листается вниз.
- **Подсказки по мере ввода** — участники этого турнира с школой, чтобы
  различить однофамильцев. Выбор подсказки оставляет схватки этого
  участника.
- **Поиск** — по фамилии и имени участника, по школе или клубу.
- **Фильтры** — чипы под строкой поиска: ковёр, весовая категория, школа,
  время (последний час, утро, день, вечер), источник (трансляция или
  медиагенты), «Мои подписки» (участники и каналы, на которые подписан
  зритель), «Мои заказы». Фильтры складываются друг с другом.
- **Группировка по времени** — заголовки с часом идут по ленте и
  прилипают к верху при прокрутке, чтобы было видно, к какому моменту
  турнира долистал.
- **«К последним»** — кнопка возврата к свежим схваткам, когда зритель
  ушёл глубоко вниз; на ней отмечено, сколько новых клипов появилось.
- **Поиск и фильтры работают на сервере**, а лента подгружается порциями
  по мере прокрутки: клиент не скачивает весь турнир, чтобы отфильтровать
  его у себя.
- Найденное сохраняется при открытии клипа: вернувшись из клипа, зритель
  видит ту же выдачу и то же место в ней.

### 2.6 Турнир без трансляции

Организатор может завести турнир и не вести трансляцию: тогда у турнира
нет каналов, и всё видео — это клипы схваток, которые снимают медиагенты.

```
 ┌──────────────────────────┐
 │ Кубок области            │   шапка вместо плеера: обложка,
 │ Организатор · 14–15 дек  │   название, организатор, даты,
 │ ● идёт турнир · 12 новых │   состояние
 │ [Подписаться] [Заказать] │
 ├──────────────────────────┤
 │ [🔍 поиск по фамилии   ] │
 │ (Ковёр 2)(до 60 кг)(Мои)→│
 ├──────────────────────────┤
 │ ┌──────┐ Иванов — Петров │   лента схваток занимает
 │ │превью│ ковёр 2 · 13:05 │   весь экран
 │ └──────┘ ♥ 12  💬 3      │
 │ …                        │
 └──────────────────────────┘
```

- **Вместо плеера — шапка события**: обложка, название, организатор, даты,
  состояние турнира, подписка и заказ съёмки.
- **Под шапкой сразу поиск, фильтры и лента** (§2.5); клипы появляются в
  ней по ходу турнира так же, как у турнира с трансляцией (§3.4).
- **Нет чата и мини-плеера** — чат принадлежит трансляции, а её нет.
  Обсуждение — в комментариях к клипам (§3.6).
- **Нет нарезки из трансляции** (§3.5) — резать не из чего; в ленте только
  клипы медиагентов.
- На компьютере то же самое: шапка во всю ширину, лента под ней.
- «С трансляцией» или «без» — не отдельная настройка: турнир без каналов и
  есть турнир без трансляции. Организатор может добавить канал позже, и
  страница сама получит плеер и чат.

## 3. Сценарии

### 3.1 Смотрю эфир и пересматриваю схватку

1. Зритель смотрит эфир турнира.
2. В ленте появляется клип только что закончившейся схватки.
3. Зритель нажимает на клип — тот начинает играть **мгновенно**, без
   заметной загрузки (§4).
4. Клип открывается в плеере поверх эфира; эфир ставится на паузу и
   продолжает буферизоваться. «Вернуться в эфир» возвращает к живой
   картинке.
5. К следующему клипу — свайпом вверх, как в вертикальной ленте (FR-42);
   следующие клипы уже загружены наперёд.

### 3.2 Горизонтальные и вертикальные клипы

- Медиагент снимает горизонтально или вертикально — как указал
  организатор или как удобнее, если организатор не указал (FR-205).
- Плеер подстраивается под клип, как на YouTube: горизонтальный клип
  показывается во всю ширину, вертикальный — во всю высоту экрана
  телефона; на компьютере вертикальный клип стоит по центру с полями.
- В ленте превью сохраняет ориентацию клипа.

### 3.3 Ищу схватку

1. Зритель начинает вводить фамилию в строке под плеером, выбирает
   участника из подсказок — лента оставляет его схватки. Фильтрами можно
   сузить дальше: ковёр, весовая категория, время (§2.5).
2. Или ищет в архиве (§3.8) — по всем турнирам.

### 3.4 Лента обновляется по ходу турнира

- Клип появляется в ленте сразу, как медиагент загрузил его и сервер
  подготовил его к показу (§4.2). Обновление приходит событием по тому же
  WebSocket, что и чат; страницу перезагружать не нужно.
- Подтверждение работы медиагента организатором (FR-243) на публикацию не
  влияет: клип виден сразу, подтверждение нужно только для денег.

### 3.5 Нарезка из трансляции

Как клипы на Twitch: организатор вырезает схватку прямо из трансляции
своего турнира, и клип встаёт в ленту под плеером.

- **Руками — сейчас.** В «Студии» организатор открывает эфир канала
  турнира — идущий или уже записанный, — ставит начало и конец схватки на
  шкале, выбирает схватку из расписания турнира (или создаёт её) и
  публикует. Во время эфира резать можно из уже записанной части, не
  дожидаясь конца трансляции.
- **По секретарю — потом.** Когда подключится приложение секретаря (FR-31),
  начало и конец схватки придут таймкодами, и клип будет вырезаться сам
  (FR-32). Организатор может поправить границы или снять клип.
- **От канала организатора.** Клип трансляции выкладывается от канала
  организатора, у которого проходит турнир, привязывается к турниру и
  схватке и встаёт в ленту под плеером.
- **Независимо от медиагента.** У одной схватки может быть и клип
  трансляции, и клип медиагента: в ленте это две карточки с подписью
  источника, а в плеере клипа — переключатель «Трансляция / Медиагент»
  между версиями одной схватки. Наличие одного на другой не влияет.
- **Композит 2×2.** Если трансляция идёт композитом, клип хранит номер
  четверти, где был ковёр, и плеер обрезает её на устройстве, как в живом
  эфире. Сервер кадр не разрезает (SRS INV-1).
- **Без перекодирования исходника.** Фрагмент вырезается из записи эфира
  копированием потока по ключевым кадрам, как весь архив; дальше для него
  готовится та же лесенка копий для доставки, что и для клипов медиагентов
  (§4.1). Для нарезки у канала должна быть включена запись — «Студия»
  предупреждает, если она выключена.
- Денег за клип трансляции нет: это работа организатора, а не заказ.
  Лайки, комментарии и статистика — как у любого клипа.

### 3.6 Лайки и комментарии

- Под каждым клипом — лайк и комментарии. Ставить лайк и
  писать комментарий может только аккаунт; гость на сайте видит счётчики и
  комментарии, но не пишет.
- Комментарий показывается с именем и аватаром автора, нажатие ведёт на
  его личную страницу — как имена в чате (FR-180).
- Счётчики просмотров, лайков и комментариев видны всем. Медиагент видит
  статистику своих клипов, организатор — клипов своего турнира; лайки и
  комментарии считаются по аккаунтам, поэтому один человек — один лайк.
- Комментарий удаляют автор, медиагент клипа и организатор турнира.

### 3.7 До и после турнира

- **До:** вместо эфира — заставка предстоящего турнира с временем начала,
  ниже расписание известных схваток (FR-200) и заказ съёмки.
- **Начало:** турнир становится идущим (`live`), когда в эфир выходит его
  канал, когда организатор нажимает «Начать турнир» или когда наступает
  дата начала — для турнира без трансляции остаются только два последних.
- **Окончание:** когда организатор завершает турнир, он считается
  оконченным (`finished`). Если организатор забыл, турнир завершается сам
  после даты окончания, когда ни один его канал не в эфире (у турнира без
  трансляции — просто после даты окончания).
- **После:** запись трансляции сохраняется на каналы турнира (FR-15), все
  клипы медиагентов — на их каналы, клипы трансляции — на канал
  организатора, и все — в ленту турнира. Вместо эфира на
  странице — записи эфиров, лента схваток остаётся целиком.

### 3.8 Архив

Раздел «Архив» на сайте и в приложении — всё прошедшее: записи
трансляций, клипы схваток, оконченные турниры.

- **Поиск** по названию, по человеку (участник, медиагент, организатор) и
  по организации.
- **Фильтры:** тип (трансляция, запись, схватка), турнир, организатор,
  дата, ковёр. Набор фильтров расширяется по мере появления данных.
- Результат ведёт на страницу турнира с открытой записью или клипом.
- Искать может кто угодно, без аккаунта.

## 4. Мгновенный старт клипов

Требование заказчика: клип начинает играть сразу по нажатию, даже на слабом
мобильном интернете, — как лента TikTok, которая загружает несколько видео
наперёд. Решение складывается из четырёх частей.

### 4.1 Что подготавливает сервер

- Медиагент загружает исходник в высоком качестве. Из него сервер делает
  **лесенку копий для доставки** в H.264 — по короткой стороне кадра
  1080/720/480/240, так что лесенка одинаково работает для горизонтальных и
  вертикальных клипов. Транскодируются копии, исходник не меняется
  (SRS INV-1); H.264 нужен потому, что HEVC с телефона играет не во всех
  браузерах.
- Клип нарезается на HLS-сегменты с **коротким началом**: первые сегменты
  по 1 с, дальше по 2–4 с. Чтобы начать показ, плееру нужен один короткий
  сегмент нижней ступени — десятки килобайт.
- Для каждого клипа готовятся **постер** (кадр) и **анимированное превью**
  в несколько секунд в самом низком качестве: их видно в ленте до нажатия.
- Сегменты клипа неизменяемы: раздаются через CDN (NFR-3) с долгим
  кэшированием, так что второй зритель получает их уже из кэша CDN.

### 4.2 Публикация

Клип попадает в ленту, когда готовы постер и нижняя ступень. Верхние
ступени дозревают после — первые зрители могут начать с 480p и подняться
выше, когда остальное будет готово.

### 4.3 Предзагрузка в клиенте

- Для клипов, видимых в ленте, и следующих 2–3 по порядку клиент заранее
  загружает плейлист, init-сегмент и **первый сегмент нижней ступени**.
- Объём предзагрузки ограничен бюджетом: на быстрой сети — до нескольких
  клипов вперёд, на медленной — только ближайший, в режиме экономии
  трафика — только постеры. Сеть оценивается по скорости последних
  загрузок; на вебе дополнительно учитываются Network Information API и
  `Save-Data`.
- Предзагрузка не мешает эфиру: она уступает полосу живому плееру и
  отменяется, когда клип ушёл из видимой области.
- Плеер клипов держит готовые декодеры для следующего клипа (на вебе —
  заранее созданный скрытый `<video>`, в приложении — заранее
  подготовленный экземпляр плеера), чтобы переход был без пустого кадра.

### 4.4 Старт воспроизведения

- По нажатию клип стартует с той ступени, первый сегмент которой уже в
  памяти, и поднимает качество, как обычно.
- Постер показывается мгновенно, пока декодируется первый кадр.

## 6. Модель данных

| Таблица | Содержание | Зачем так |
|---|---|---|
| `Event` | `+coverPath` (nullable), `+startedAt`, `+endedAt` (nullable) | Обложка для шапки (FR-308), моменты начала и окончания (FR-306). Есть ли трансляция — по наличию `Stream` с этим `eventId`, отдельного поля нет |
| `Clip` | **Новая**: `id`, `eventId`, `boutId`, `source` (`agent` \| `broadcast`), `channelStreamId` (канал, от которого выложен клип), `createdByAccountId`, `boutShootId` (nullable, для клипа медиагента), `agentAccountId` (nullable), `broadcastId` (nullable, для клипа трансляции), `startOffset`, `endOffset` (nullable, границы в эфире), `quad` (nullable, четверть композита), `cutMode` (`manual` \| `secretary`, nullable), `status` (`processing` \| `published` \| `failed` \| `removed`), `orientation` (`landscape` \| `portrait`), `width`, `height`, `duration`, `posterPath`, `previewPath`, `manifestPath`, `renditions Json`, `viewCount`, `likeCount`, `commentCount`, `publishedAt`, `createdAt` | Опубликованный клип схватки из любого источника. S3-ключи по той же схеме, что у архива; `renditions` показывает, какие ступени уже готовы; счётчики — агрегат (NFR-88). Две версии одной схватки — две строки с одним `boutId` |
| `ClipLike` | **Новая**: `clipId`, `accountId`, `createdAt`; первичный ключ `(clipId, accountId)` | Один аккаунт — один лайк |
| `ClipComment` | **Новая**: `id`, `clipId`, `accountId`, `content`, `createdAt`, `deletedAt` (nullable), `deletedByAccountId` (nullable) | Комментарии; имя и аватар берутся из `Account` при выдаче |
| `Bout` | `+weightClass` (nullable) | Пара, ковёр, время и весовая категория для подписи и фильтров; аватары и школа — из аккаунтов участников через `Registration` |

Индексы: `Clip(eventId, publishedAt)` для ленты, `Bout(eventId, venue)`,
`Bout(eventId, weightClass)` для фильтров, `ClipComment(clipId,
createdAt)`. Поиск по участникам турнира — по `AccountRole.searchName`,
школе и именам в `Bout` в пределах одного турнира. Поиск в архиве — по названиям турниров и записей, по
`AccountRole.searchName`, именам в `Bout` и `Account.displayName`;
движок полнотекстового поиска выбирается вместе с поиском по сайту (FR-16).

Просмотры считаются обезличенно, как телеметрия плеера: счётчик, а не
журнал «кто смотрел».

## 7. Интерфейсы API (эскиз)

| Маршрут | Назначение | Кто |
|---|---|---|
| `GET /v1/public/events/:id` | Страница турнира: каналы, статус, расписание | без авторизации |
| `GET /v1/public/events/:id/clips?q=&participant=&school=&venue=&weight=&from=&to=&mine=&cursor=` | Лента схваток с поиском и фильтрами, порциями: постер, превью, ориентация, пара, аватары, счётчики, адрес медиа, заголовки групп по времени. `mine` (подписки, заказы) — только для аккаунта | без авторизации |
| `GET /v1/public/events/:id/participants/suggest?q=` | Подсказки участников турнира со школой | без авторизации |
| `GET /v1/public/clips/:id/hls/*` | Плейлисты и сегменты клипа; тяжёлые байты — редиректом на CDN | без авторизации |
| `PUT/DELETE /v1/me/likes/:clipId` | Лайк клипу и его снятие | аккаунт |
| `GET /v1/public/clips/:id/comments`, `POST /v1/clips/:id/comments`, `DELETE /v1/clips/:id/comments/:commentId` | Комментарии | чтение — все; запись — аккаунт; удаление — автор, медиагент, организатор |
| `GET /v1/me/clips/stats`, `GET /v1/org/events/:id/clips/stats` | Статистика клипов медиагента и турнира | медиагент, владелец организации |
| `GET /v1/public/archive?q=&type=&event=&org=&from=&to=&venue=&cursor=` | Поиск и фильтры архива | без авторизации |
| `POST /v1/org/events/:id/start`, `POST /v1/org/events/:id/finish` | Начать и завершить турнир | владелец организации |
| `PUT /v1/org/events/:id/cover` | Обложка турнира | владелец организации |
| `POST /v1/org/events/:id/clips`, `PATCH /v1/org/events/:id/clips/:clipId`, `DELETE …` | Нарезка из трансляции: эфир, начало, конец, схватка, четверть композита; правка границ, снятие | владелец организации |
| WebSocket `/chat`, события `clip_published`, `clip_counters` | Новый клип и счётчики в ленте турнира | все в комнате турнира |

Адреса медиа клипов выдаёт сервер, клиент их не строит (SRS NFR-52).
